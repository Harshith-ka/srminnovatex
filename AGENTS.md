# Development Notes

This project uses TanStack Start (v1) with Vite, TailwindCSS v4, and TypeScript.

## Stack
- **Framework**: TanStack Start + TanStack Router (file-based routing)
- **UI**: Tailwind CSS v4, shadcn/ui components (Radix UI)
- **Data fetching**: TanStack Query
- **Build**: Vite + Nitro (for SSR/server)

## Commands
```bash
bun dev        # Start dev server
bun build      # Production build
bun preview    # Preview production build
```

## File conventions
- Routes live in `src/routes/` — files map to URL paths automatically
- `src/routeTree.gen.ts` is auto-generated by TanStack Router, do not edit manually
- UI components from shadcn/ui are in `src/components/ui/`
